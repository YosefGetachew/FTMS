# FTMS Mobile

Expo mobile client for the Foreign Travel Management System.

## Run

```powershell
npm install
npm start
```

Use `EXPO_PUBLIC_API_URL` to point the app to the FTMS backend.

- Production: `https://ftms.moa.gov.et/api`
- Android emulator: `http://10.0.2.2:5000/api`
- iOS simulator: `http://localhost:5000/api`
- Physical phone: `http://YOUR_COMPUTER_LAN_IP:5000/api`

For local testing, the backend must be running from the FTMS `backend` folder.
